- `Feature ideas`

## Recognition ideas

- Thank first-time contributors explicitly in PR merges
- Add a `Contributors` section to the README once the project has multiple external contributors
- Use release notes to credit meaningful community changes

## Signals that make the project feel active

- Keep roadmap updates public
- Keep a few `good first issue` items open at all times
- Respond quickly to first PRs and first issues
- Close stale ambiguity by labeling and scoping issues clearly
