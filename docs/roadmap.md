# Roadmap

## Current scope

PIDIEF is a lightweight browser-based PDF workflow tool focused on:

- merging imported PDFs
- reordering and managing pages
- adding simple annotations
- exporting a final document locally

The project is intentionally not trying to become a full desktop publishing suite or a cloud document platform.

## Near-term improvements

- Undo and redo improvements
- Better page thumbnails and page navigation polish
- Clearer import and export error states
- Better mobile and touch interactions
- Accessibility pass for keyboard and screen reader support
- More automated tests around state and export behavior

## Medium-term improvements

- Split PDF workflow
- Page thumbnails sidebar improvements
- Keyboard shortcuts overlay and discoverability
- Performance improvements for larger PDFs
- Better annotation selection and alignment tools
- PWA and offline support

## Nice-to-have ideas

- Additional annotation types
- Export/import annotation layers separately from source PDFs
- Smarter page labels and footer presets
- Drag-and-drop multi-file import polish
- Optional local persistence between sessions
